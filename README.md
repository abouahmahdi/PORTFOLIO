# Portfolio — Elmahdi Abouah

## Fichiers
- `index.html` : structure et contenu du portfolio.
- `style.css` : design responsive.
- `script.js` : menu mobile, animations et navigation active.
- `hero-workspace.png` : image de couverture.

## Lancer le portfolio
1. Garder les quatre fichiers dans le même dossier.
2. Ouvrir `index.html` dans un navigateur, ou lancer le dossier avec l'extension Live Server de VS Code.
